# Веб-портал для навчання дітей «Розумники» (CSS Styling)

Лабораторна робота №2 з дисципліни «Розробник фронтенду програмних систем».
Тема: Стилізація елементу інтерфейсу засобами CSS.
Варіант: №4.

## Використані технології та концепції
- Модулі розмітки: CSS Grid (головна сторінка, курси) та CSS Flexbox (зворотний зв'язок).
- Стиль дизайну: Мальований / ігровий стиль для дитячого порталу.
- Зовнішня та внутрішня таблиці стилів.
- 2D-трансформації, переходи (transitions) та анімації фільтрів.
